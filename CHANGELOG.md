# Changelog

## [1.0.7] - 2025-04-01

- Added "Tree" command to generate directory structure trees
- Tree command respects .gitignore patterns
- Tree command excludes common system files and directories (.git, .vscode, etc.)
- Tree command has a maximum depth of 10 levels

## [1.0.6] - 2025-03-31

- Added code review feature using Claude API
- Added custom commands feature
- Implemented "skim mode" to strip function bodies
- Changed output to editor tabs instead of saving to files
- Added recursively processing directories

## [1.0.0] - Initial Release

- Initial version of CodeCat
- Basic concatenation functionality
- Copy to clipboard
