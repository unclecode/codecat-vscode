# CodeCat VSCode Extension

Concatenate multiple selected files and copy their contents to clipboard. You can easily paste in your LLM Chat application to ask questions or generate code.

## Features

- Right-click on files in Explorer and select "Concat" to combine their contents
- Contents are copied to clipboard with file headers
- Supports any text file type

## Usage

1. Select multiple files in VSCode Explorer
2. Right-click and choose "Concat"
3. The combined content will be copied to your clipboard
4. Paste anywhere you need

## Requirements

- Visual Studio Code 1.98.0 or higher
